# NIPAP 0.32.7+axians.3 for Debian 13

This release fixes XML-RPC socket cleanup in `pynipap`, used by the web interface,
CLI and Python clients. Debian package version: `0.32.7+axians.3-1`.

## Changes since axians.2

- Close the XML-RPC transport after every client operation, including successful
  requests, XML-RPC faults and HTTP errors. Previously discarded connections could
  produce `ResourceWarning: unclosed <socket.socket ...>` messages.
- Preserve existing authentication, exception mapping and browser login sessions.
  The client already created a separate connection for each operation; this release
  makes cleanup explicit.
- Add three regression tests using a real HTTP keep-alive server. The tests verify
  that connections close before garbage collection and that errors retain their
  original meaning. Run them in both regular CI and installed-package tests.

The Debian 13/systemd support, light/dark themes and administrator-only audit
viewer from axians.2 are included. Database schema version remains **8**.

## Installation and upgrades

Download the five core packages: `nipap-common`, `nipapd`, `python3-pynipap`,
`nipap-www` and `nipap-cli`. `nipap-whoisd` is optional.

For a new Debian 13 server receiving a database migration, follow the attached
`INSTALL-debian13.md`. Migration from NIPAP 0.29.8 / PostgreSQL 9.6 still requires
a rehearsal and verification of schema 6 → 7 → 8, authentication and configuration.

For an existing axians.2 installation, download this release's packages and
`SHA256SUMS` into a separate directory, verify the downloads, then install:

```sh
sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./nipap-common_*.deb ./nipapd_*.deb \
  ./python3-pynipap_*.deb ./nipap-www_*.deb ./nipap-cli_*.deb
```

No database schema migration is introduced by this update. Restart web workers and
any long-running Python clients to load the updated client library. For the
documented Apache deployment, restart `apache2` after installation.

## Validation and artifacts

Publication requires successful clean Debian 13 package builds, Lintian checks,
and installation testing with PostgreSQL 17. The suite contains 161 tests covering
connection cleanup, startup, the audit viewer, XML-RPC, backend operations, CLI,
read-only access and REST, plus packaged web login and asset smoke checks.

`SOURCE_COMMIT` records the exact source commit. `source-and-build-records.tar.gz`
contains Debian source packages and build/test records. `SHA256SUMS` covers the
downloadable release assets.

Separate configuration-file and SQLite cleanup warnings remain. Host reboot,
production TLS and migration of your existing database must be verified on the
destination before cutover.
