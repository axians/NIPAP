# NIPAP 0.32.7+axians.4 for Debian 13

This release fixes readability in the dark theme and improves the Debian 13
installation instructions. Debian package version: `0.32.7+axians.4-1`.

## Changes since axians.3

- Give login errors and logout confirmations explicit text and background colors
  in both themes.
- Fix the contrast of green action buttons, including Add VRF, Add pool and
  Add prefix, with hover, focus and pressed states.
- Make dropdown entries readable in dark mode, including the Add prefix menu,
  keyboard focus, active entries and disabled entries.
- Add a visible, clickable **Mode** label next to the theme switch.
- Link the existing favicon from the shared page template.
- Shorten the audit navigation label and page heading to **Audit**.
- Use Deb822 `nipap.sources` in the installation guide and release tests.
- Document `WSGIApplicationGroup %{GLOBAL}` for Apache, resolving the psycopg2
  import failure observed with Python 3.13 under mod_wsgi subinterpreters.
- Clarify audit database permissions and the separate interactive password step.
- Check the installed login page and favicon through Apache/mod_wsgi in release CI.

The XML-RPC connection cleanup from axians.3 is retained. Database schema version
remains **8**. Audit reads still use the configured read-only PostgreSQL connection;
this release does not move audit queries into the XML-RPC API.

## Installation and upgrades

Download the five core packages: `nipap-common`, `nipapd`, `python3-pynipap`,
`nipap-www` and `nipap-cli`. `nipap-whoisd` is optional.

For a new Debian 13 server receiving a database migration, follow the attached
`INSTALL-debian13.md`. For an existing axians.3 installation, download this
release's packages and `SHA256SUMS` into a separate directory, then run:

```sh
sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./nipap-common_*.deb ./nipapd_*.deb \
  ./python3-pynipap_*.deb ./nipap-www_*.deb ./nipap-cli_*.deb
```

Keep `WSGIApplicationGroup %{GLOBAL}` in the NIPAP Apache virtual host. If missing,
add it alongside `WSGIScriptAlias` before restarting the web application:

```sh
sudo apache2ctl configtest && sudo systemctl restart apache2
```

Hard-refresh the browser to load the updated styles. No database schema migration
is introduced. Existing audit installations retain their `audit_admins` and
`audit_db_dsn` settings. The SysV compatibility script remains packaged; systemd
hosts use the native service.

## Validation and artifacts

Publication requires clean Debian 13 package builds, Lintian checks, the 161-test
installed-package suite against PostgreSQL 17, and web, CLI and Apache smoke checks.
The theme changes have calculated text contrast checks; a browser visual review
was not completed in the local build environment.

`SOURCE_COMMIT` records the exact source commit. `source-and-build-records.tar.gz`
contains Debian source packages and build/test records. `SHA256SUMS` covers the
downloadable release assets. Configuration-file and SQLite cleanup warnings from
earlier releases remain.
