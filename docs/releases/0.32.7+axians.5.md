# NIPAP 0.32.7+axians.5 for Debian 13

This release fixes unreadable VRF and pool success messages in dark mode.
Debian package version: `0.32.7+axians.5-1`.

## Changes since axians.4

- Replace the inline pale-green backgrounds on VRF and pool add/edit
  confirmations with a shared success-message style.
- Use pale-green text on a dark-green background in dark mode, and dark-green
  text on a pale-green background in light mode.
- Keep the existing dark-mode styling for prefix add/edit confirmations.

All previous Axians 4 fixes are retained. Database schema version remains **8**;
this release introduces no database migration or authentication changes.

## Installation and upgrades

Download the five core packages: `nipap-common`, `nipapd`, `python3-pynipap`,
`nipap-www` and `nipap-cli`. `nipap-whoisd` is optional.

For a new Debian 13 server receiving a database migration, follow the attached
`INSTALL-debian13.md`. For an existing Axians installation, download this
release's packages and `SHA256SUMS` into a separate directory, then run:

```sh
sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./nipap-common_*.deb ./nipapd_*.deb \
  ./python3-pynipap_*.deb ./nipap-www_*.deb ./nipap-cli_*.deb
```

Hard-refresh the browser to load the updated styles and Angular templates.
Existing configuration settings remain applicable.

## Validation and artifacts

The VRF, pool and prefix add/edit result markup was rendered in headless Firefox
and visually checked in both themes. The new success-message color pairs have
text contrast ratios of 9.17:1 in dark mode and 9.75:1 in light mode.

Publication requires clean Debian 13 package builds, Lintian checks, the
installed-package test suite against PostgreSQL 17, and web, CLI and Apache
smoke checks.

`SOURCE_COMMIT` records the exact source commit. `source-and-build-records.tar.gz`
contains Debian source packages and build/test records. `SHA256SUMS` covers the
downloadable release assets.
