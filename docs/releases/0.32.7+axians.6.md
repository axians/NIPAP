# NIPAP 0.32.7+axians.6 for Debian 13

This release fixes dark-mode tag readability and incorporates the current Axians
master dependency updates. Debian package version: `0.32.7+axians.6-1`.

## Changes since axians.5

- Make tag text readable in dark mode, including selected tags and the remove
  button's hover state.
- Update the Python source dependency pins: PyJWT 2.15.0 (SpriteLink #1469),
  certifi 2026.10.19 (#1470), Werkzeug 3.1.9 and Tornado 6.5.9.
- Align optional LDAP dependencies on python-ldap 3.4.5 in the backend and web UI.
- Retain previous Axians fixes, including XML-RPC connection cleanup, light/dark
  theme styling, the administrator-only Audit view and Debian 13/systemd support.

The Debian packages use dependencies supplied by the configured APT repositories;
the Python pins above apply to pip/source installations, not bundled Debian
libraries. Installed Debian dependency versions are recorded with the build logs.
Database schema remains **8**; this release introduces no database migration or
new authentication flow.

## Installation and upgrades

Download the five core packages: `nipap-common`, `nipapd`, `python3-pynipap`,
`nipap-www` and `nipap-cli`. `nipap-whoisd` is optional.

For a new Debian 13 server receiving a database migration, follow the attached
`INSTALL-debian13.md`. For an existing Axians installation, download this
release's packages and `SHA256SUMS` into a separate directory, then run:

```sh
sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./nipap-common_*.deb ./nipapd_*.deb \
  ./python3-pynipap_*.deb ./nipap-www_*.deb ./nipap-cli_*.deb
sudo systemctl restart nipapd apache2
```

Keep `WSGIApplicationGroup %{GLOBAL}` in the Apache virtual host. Restart any
other long-running web workers or Python clients and hard-refresh the browser
to load the updated styles. Existing configuration settings remain applicable.

## Validation and artifacts

Publication requires clean Debian 13 package builds, Lintian checks, the
installed-package test suite against PostgreSQL 17, and web, CLI and Apache
smoke checks. The updated PyJWT and certifi pins were also checked in an isolated
Python environment using RSA JWT verification, rejection of invalid and expired
tokens, certificate-bundle loading and an HTTPS request with certificate
verification enabled.

`SOURCE_COMMIT` records the exact source commit. `source-and-build-records.tar.gz`
contains Debian source packages and build/test records. `SHA256SUMS` covers the
downloadable release assets.
