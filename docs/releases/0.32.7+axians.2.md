# NIPAP 0.32.7+axians.2 for Debian 13

Axians release based on upstream NIPAP 0.32.7 and Axians master, with Debian
package version `0.32.7+axians.2-1` and database schema version **8**.

## Changes

- Debian 13 packaging and a native `nipapd.service` running as `nipap:nipap`.
- Preserve supplementary service groups and check TLS files before startup.
- Preserve administrator choices for database initialization and upgrades.
- Persistent light/dark web themes.
- Administrator-only audit viewer with filtering and pagination. This feature
  is disabled until explicitly configured; see `docs/audit-log.rst` in the source.
- Current Axians dependency updates.
- Tagged package builds, installation tests, checksums and permanent release assets.

## Installation

Download `nipap-common`, `nipapd`, `python3-pynipap`, `nipap-www` and `nipap-cli`.
`nipap-whoisd` is optional. Follow the attached `INSTALL-debian13.md` instructions.
The packages use Debian's Python packages. The supplemental NIPAP APT repository
is required for dependencies unavailable in Debian 13 itself.

`SOURCE_COMMIT` identifies the exact source commit. `source-and-build-records.tar.gz`
contains Debian source packages, build metadata, Lintian output, and installation
test logs. `SHA256SUMS` covers the release assets.

## Migration from 0.29.8 / PostgreSQL 9.6

Install on a separate Debian 13 server and rehearse a logical database restore
before cutover. Verify the restored NIPAP schema version; the supplied migrations
cover schema 6 to 7 to 8. Transfer local authentication separately if used.

Package installation tests do **not** certify migration of an existing production
database. The production dump, ip4r extension, local users, application configuration
and client integrations must be validated on the destination before switching traffic.
Keep the source installation available until the migration is accepted.

## Validation performed by the release workflow

- Clean Debian 13 chroot builds and Lintian checks for all source projects.
- Installation of the five core binary packages on Debian 13 with PostgreSQL 17.
- Existing startup, audit viewer, XML-RPC, backend, CLI, read-only and REST tests
  against installed packages.
- Packaged web login, static asset presence and embedded schema migrations.

The container checks do not test a host reboot or the production TLS certificate.
Verify those on the destination host before cutover.

Python's test runner reports existing `ResourceWarning` messages for configuration
file, SQLite and XML-RPC connection cleanup. These warnings remain visible in the
test logs; they do not indicate configuration parsing failures.
